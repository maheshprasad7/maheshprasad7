## 👨‍💻 ABOUT ME

> *"Don't stop when you're tired. Stop when you're done." - David Goggins*

<img align="right" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" width="280" />

I'm a **1st-year CSE undergrad** at Vidyavardhaka College of Engineering, Mysuru. I love bridging the gap between clean UI and powerful backends — building full-stack apps that solve **real-world problems**, while continuously learning and exploring new technologies.

- 💻 **Tech Stack Explorer** — Deep diving into Full Stack Web Dev (Next.js, React, Supabase) & AI integrations.
- 🌾 **Impact-Driven Builder** — Created platforms like Krishi-Setu and CampusBook-AI to solve practical challenges.
- 🤖 **AI Enthusiast** — Passionate about building intelligent, AI-powered solutions.
- 📸 **Creative & Active** — When I'm not coding, you'll find me doing photo/videography, editing videos, or playing cricket!
